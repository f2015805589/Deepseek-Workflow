# dsh-client-ui-engineering-mode — 工程模式插件

一个随 DeepSeek Workflow 桌面仓库发布的自定义插件（双面）：

- **浏览器半**（`lib/client.js`）：
  - 向 `sidebar.footer.action` 槽注册「工程模式」入口。
  - 向 `shell.overlay` 槽注册**独占右侧主窗口**的工程面板：覆盖对话列和详情列，保留左侧工作区/会话侧栏可用。
  - 不向 `conversation.view` 注册任何标签，因此普通对话里不会出现「工程模式」标签；工程模式不再是某个会话的视图，而是独立占用右侧窗口。
  - 面板没有普通会话标题、视图标签和普通输入框，上方只有工程模式自身标题，下方是工程模式自己的输出框。
  - 顶部需求区、队列/进行中、已完成三个模块可分别选择运行模式（agent preset）和模型/思考程度，默认 `minimal-powershell`。
  - 需求区与看板之间、看板与输出框之间可拖动调整高度。
  - 规划期间和任务执行期间显示「执行计划」卡片。
  - 任务卡片支持拖放、停止/继续、按依赖和并行度同时执行。
  - 所有会话归属用户选择的工作区，标题使用 `工程模式｜<工作区>｜...` 前缀。
- **宿主半**（`lib/index.js`）：提供可单测的纯函数（assistant 文本提取、任务 JSON 解析、最优拆分合并、相似度计算）。

流程：

1. 点击侧栏「工程模式」，选择工作区，插件创建工程面板会话并打开右侧独占面板。
2. 分别选择规划 / 执行 / 合并验证的运行模式、模型和思考程度，设置并行度。
3. 输入需求并开始：`/plan` → 计划生成（Plan 卡片）→ 最优任务拆分 → 任务入队。
4. 队列任务按依赖与并行度进入「进行中」，完成后进入「已完成」。
5. 队列清空后使用已完成列配置合并验证，结果输出到下方输出框。

- 包名 = 文件夹名（自定义插件发现契约）。
- `plugins/plugins.json` 默认启用本插件。
- 无构建步骤：浏览器半是手写的 ModuleLoader 闭包格式 bundle，与随包 UI 插件的产物同构。
